# Correlation-Analysis-in-R
A small practice project exploring correlation analysis between gene expression and clinical variables in R.

The analysis uses the publicly available Real Colorectal Cancer Dataset obtained from Kaggle:
https://www.kaggle.com/datasets/amandam1/colorectal-cancer-patients/data

Workflow
Probe annotation and gene-level expression preparation
Selection of highly variable genes
Normality testing
Spearman correlation
Correlation significance testing
Correlation matrices and heatmap visualization

The project is intended as a practical introduction to correlation analysis for transcriptomic and clinical data.
